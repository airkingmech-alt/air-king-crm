save keeps inputs, and successful save opens the normal proposal route.

REOPENING AND EDITING
Saved inputs reopen as a historical view. Edit takeoff as new draft restores
all eight editable sections and saves a separate quote with sourceQuoteId in its
private snapshot. It does not overwrite the original record, manual prices,
scope, add-ons, accepted scope or approvals. The UI explicitly explains that a
new draft recalculates from takeoff inputs and does not copy proposal adjustments.
The existing View / edit saved proposal route retains normal in-place pricing
and scope edits with existing conflict/audit/accepted-document protections.
This copy workflow is not a replacement for the CRM's formal accepted-quote
revision endpoint or an automatic replacement of a customer-approved proposal.
Current equipment IDs/costs are validated; obsolete saved costs require reselecting
models rather than silently changing them. Original allowances remain reviewable.

UNSAVED WORK
Session-storage recovery is keyed by company, staff user and source quote. It
restores inputs after route navigation, browser Back and refresh in the same tab.
It is not a server save or cross-device draft; save before closing the tab.
Cancel shows Keep working / Discard takeoff. Discard removes the recovery copy;
successful save clears it. If storage fails, a visible warning, unload warning
and link guard protect against silent loss (browser Back under unavailable
storage remains a platform limitation). No new persistent credentials are used.

PRICING AND CUSTOMER PRIVACY
Uses existing cents-based CRM formula: 9% equipment + materials purchase tax,
untaxed labor, total cost divided by 0.80. Original Site equipment-only taxation
was intentionally replaced by the established CRM rule. Historical prices and
ordinary quote calculations were not changed. Invalid costs, quantities, catalog
IDs and categories are rejected. Duct/trade allowances need supplier confirmation.
The Manual J worksheet is an estimating aid, not a certified design; final
manufacturer/AHRI matching and sizing require normal professional review.
Customer scope contains a generic installation description for review in the
proposal editor, not crew days, subcontract allowances or private notes.
Existing public-field allowlists omit the takeoff snapshot and internal costs;
internal proposal costs remain no-print. No snapshot was added to customer
pages, print, email or SMS output. Public serialization privacy is tested.
