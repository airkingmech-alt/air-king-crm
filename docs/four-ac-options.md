# Four AC / furnace / coil options

Prepared on master `03a7e8a` (includes PR #61 document numbering). No live data changes, migrations, merge, deployment, publication, or customer messages were performed.

## Behavior

Complete AC/furnace/coil selections are evaluated as four fixed option identities:

| Saved identity | Offering | Coverage | Added labor warranty job cost |
| --- | --- | --- | --- |
| Value | Cheapest reviewed compatible Guardian AC + Guardian furnace + selected Champion coil | 10-year parts only | $0 |
| Good | Champion XC3, 13.4 SEER2 series + selected Champion furnace and coil | 10-year parts and labor | $250 |
| Better | Champion XC4, 14.3 SEER2 series + same Champion furnace and coil | 10-year parts and labor | $250 |
| Best | Champion XC6, 16+ SEER2 series + two-stage Champion furnace retaining selected AFUE + same coil | 10-year parts and labor | $250 |

Candidate substitutions preserve selected cooling capacity, furnace input/cabinet/blower code, AFUE, coil, accessories and labor/material/scope inputs. Furnace catalog tonnage is not used as cooling airflow. Guardian selection sorts actual compatible model costs, without multipliers. A reviewed exact condenser/coil/furnace match is required. The top option also requires exact-model furnace AFUE and two-stage evidence in the match registry. Series efficiency labels are separate from the reviewed matched-system SEER2 rating.

The builder shows all four candidate cards with exact blockers. Only valid options are saved. If none is valid, saving is blocked. Blockers for omitted options are retained in the draft's internal review note. No blocked candidate is presented as a purchasable customer option. Existing saved quotes are never regenerated by rendering. Heat pump, mini-split, maintenance, and non-complete-AC-system paths retain their existing behavior.

The public/staff layouts support four cards (one column on mobile, two on medium screens, four on large screens). Four-card print/PDF layouts use two columns for legibility. The fourth identity passes through existing option-based acceptance, invoice, and scheduling paths. A local migration raises the database edit guard from three to four options and permits Value; it changes no customer rows. It aborts if the expected current guard has drifted. Deploying this code requires that migration to be reviewed and applied under separate approval.

## Actual catalog and blockers

The quote builder and draft factory use `client/src/data/pricebook.ts`, sourced in-file from Kearney Winsupply dated 2026-02-05. They do not read the separate CRM materials/price-book table. That actual builder catalog was inspected; neither catalog was edited.

- The reviewed registry contains XC342E2S11 / CTM42C5CES1 / Z9ES080C20SMPS1 (AHRI 214727374, 13.4 SEER2), XC442E2S11 with the same indoor equipment (215419289, 14.3 SEER2), and XC648E2S11 / CTM48C5CFS1 / Z9ES080C20SMPS1 (216586593, 15.75 SEER2). These are existing repository review records, not new certification obtained during this change.
- There are no reviewed Guardian combinations. Exact Guardian model/furnace/Champion-coil compatibility evidence is still needed.
- There is no priced Z8ET / 80% two-stage Champion furnace in the builder catalog.
- Z9ET entries are labeled 96% in the catalog, while the current manufacturer series page lists 97%. Exact-model AFUE confirmation is needed before substituting one for selected 96% equipment. No pricebook correction was made.
- There are no reviewed XC6 / two-stage furnace / unchanged selected coil combinations. Existing XC6 evidence uses a single-stage furnace and, for the former 3.5-ton upgrade, a different coil. It does not satisfy this request.
- No 2.5- or 3.5-ton XC6 is priced. The catalog includes a 1.5-ton XC618; no blanket whole-ton rule is inferred. Capacity is never rounded up.
- Example selected 3.5-ton XC342 + Z9ES080C20 + CTM42 produces only valid options 2 and 3. Option 1 lacks a matching priced Guardian C20 furnace; option 4 lacks same-capacity XC6. Other selections may have no reviewed combinations and therefore cannot be saved automatically.

## Preserved pricing conflicts

The existing builder defaults remain $1,200 labor and $450 materials. Existing shared pricing taxes equipment **and materials** at 9%, then divides job cost by 0.80. These differ from the current Air King skill's $960 labor, $200 misc and equipment-only tax. This options change deliberately does not alter those unrelated defaults or reprice historical quotes. The requested Champion warranty adds a separate untaxed $250 job cost; Guardian omits it. Staff preview explicitly distinguishes the baseline estimate from option warranty pricing. Manual equipment edits clear obsolete coverage and its allowance for review.
