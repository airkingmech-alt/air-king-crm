# Homeowner equipment descriptions

Quote options display brand, nominal size, and verified catalog efficiency instead of raw model numbers. Example: 3-ton, 13.4 SEER2 Champion AC; 3-ton Champion coil; 97% efficient, 80,000 BTU Champion furnace for Z9ET080B12SMPS1. Z9ES080B12SMPS1 remains 96%; Z9ET100C16 and C20 retain their actual 96.8% and 96.4% labels. No SEER2 value is relabeled SEER and no AHRI installed-system rating is invented.

New options snapshot friendly equipment lines and an equipment summary. Internal model strings, selected IDs, costs, warranty choices, rebate evidence and option identities remain intact. Existing records are never rewritten. Legacy views use saved descriptions rather than today's mutable pricebook; unknown specifications are not inferred. Recalculating equipment refreshes descriptions; manual free-text replacement clears the old description snapshot.

Homeowner public pages, option cards, selected-equipment summaries and PDF output use these saved descriptions. Raw models and detailed installation review notes remain accessible in staff-only print-hidden details. Scope/title substitutions affect exact known model tokens only and preserve surrounding scope and exclusions. Rebate amounts and program conditions are unchanged; customer rebate headings use equipment type rather than model number. Existing efficiency disclosure and warranty terms remain.

Future accepted invoice descriptions naturally receive the new friendly summary through the existing snapshot builder. Existing accepted snapshots and invoices are not changed. No database migration or pricebook update is needed.
